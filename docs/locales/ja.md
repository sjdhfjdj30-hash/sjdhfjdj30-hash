# はじめまして、シニアシステムエンジニアのマーカス・ヴァンス（Marcus Vance）です 👋

**低遅延ネットワーキング**、**組み込みストレージエンジン**、および**分散合意プロトコル**を専門とするシニアシステムソフトウェアエンジニアです。

ハードウェア親和的設計（Mechanical Sympathy）、ゼロアロケーション（Zero-allocation）通信プロトコル、および耐障害性の高いクラッシュリカバリ機構を重視し、堅牢な高並行インフラを構築しています。ソフトウェアは本質的に高速で、明快であり、第一原理（First-principles）に基づいて信頼性が高くなければならないと考えています。

## 📐 エンジニアリング哲学

- **ハードウェア親和性（Mechanical Sympathy）**: コードを最適化する前に、メモリ階層、CPUキャッシュライン境界、分岐予測器の物理的動作を理解する。
- **推測ではなくベンチマーク**: 「神のみを信じよ。それ以外のすべては再現可能なマイクロベンチマークとフレイムグラフで証明されなければならない。」
- **クラッシュ前提設計（Crash-Only Design）**: いかなる命令の実行中に突然の電源断やSIGKILLが発生しても、データ整合性を維持してクリーンに復旧可能でなければならない。
- **最小限の依存関係**: 最良のライブラリ依存とは、追加しなかった依存関係である。依存グラフを小さく堅牢に保つ。
