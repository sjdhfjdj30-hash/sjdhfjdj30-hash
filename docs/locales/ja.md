# こんにちは、マーカス・ヴァンス（Marcus Vance）です 👋

**超低レイテンシ・ネットワーキング**、**組み込みストレージエンジン**、および**分散合意アルゴリズム**に特化したシステムソフトウェアエンジニアです。

ハードウェアへの親和性（Mechanical Sympathy）、ゼロアロケーション（Zero-allocation）通信プロトコル、およびクラッシュ時にも安全に自己修復する耐障害アーキテクチャを重視したインフラを設計・構築しています。ソフトウェアは本質的に高速で、簡潔で、可観測（Observable）であるべきだと考えています。

## 📐 エンジニアリングの原則

- **メカニカル・シンパシー（ハードウェア協調）**: コードの最適化に着手する前に、メモリ階層、CPUキャッシュラインの境界、分岐予測器の挙動を深く理解すること。
- **推測ではなくベンチマーク**: 「神のみを信じよ、それ以外の者は再現可能なマイクロベンチマークとフレームグラフを持参せよ。」
- **クラッシュ前提の設計（Crash-Only Design）**: いかなるストレージシステムも、任意の命令実行中に生じる突然の電源断やSIGKILLからクリーンにデータ整合性を保って復旧できなければならない。
- **最小限の依存関係**: 最良の依存ライブラリとは、最初から追加しなかったものです。依存ツリーを極限までコンパクトかつ堅牢に維持します。
